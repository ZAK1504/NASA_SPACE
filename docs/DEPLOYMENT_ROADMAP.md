## 3. Backend
After approval, signup OCI Free account; confirm home-region A1 capacity (India region if eligible), only Always Free shape/image and storage. Target 2 OCPU 12 GB, 50 GB boot + 100 GB block volume, Ubuntu ARM64. No upgrade or extra resources without approval. Verify pricing estimate $0 and quotas; if capacity fails do not pay automatically. Use dedicated nonroot service account, persistent mount /srv/horizon-data, code /opt/horizon/releases/<sha>. Install validated Python environment and dependencies; verify ARM imports/tests. Run from backend: uvicorn app.main:app --host 127.0.0.1 --port 8000, managed by systemd with restart on failure and resource bounds. Configure environment and writable MPLCONFIGDIR. Reverse proxy HTTPS Caddy/Nginx, stable endpoint with valid cert; use domain if claimed, or verify reserved IP and automated short-lived Let's Encrypt IP TLS before choosing domainless route. Test curl -fsS https://<api-host>/api/health and actual browser CORS. No expose port 8000. Rollback release symlink and service restart.
## 4. Persistence
Mount separate volume before service startup, ensure mount dependency and ownership. Make cache path configurable and preserve data on redeploy. Copy only validated demo products via secure transfer or download from IRSA; maintain manifest checksums, protect pinned assets. Keep user records private and migrate/export with approval. Daily small encrypted backup of non-regenerable data; verify restore; use included volume backups within quota. Do not copy private journal into public static site. Rollback restore versioned backup, not cache deletion.
