# SPHEREx HORIZON — Hosting architecture audit

Audit date: 2026-11-15. Source snapshot: [main 14286d5](https://github.com/ZAK1504/NASA_SPACE/tree/14286d5a69a92059a8b22761ee73fb4b20215510). All provider links below were consulted or identified for verification on this date. Findings are static-source observations, not deployed benchmarks. No cloud resources, billing, or application code were changed.

## Executive decision
Prefer Cloudflare Pages (static React) + one OCI Always Free Ampere A1 VM (FastAPI, persistent cache) after security and ARM gates. Alternative: same-origin Caddy/Nginx + static dist + FastAPI on that VM; fallback: request-billed Cloud Run plus bounded object storage. Zero recurring infrastructure cost is conditional, not guaranteed; no provider offers guaranteed unlimited free scientific processing or high availability. Do not use temporary trial credits as a permanent solution.

## Architecture
A: Cloudflare Pages -> HTTPS API hostname -> Caddy/Nginx -> loopback FastAPI -> persistent OCI block volume / IRSA. Static CDN independent of VM. Use public stable TLS endpoint, preferably NASA domain while valid; no-domain alternative: reserved public IP and automated Let's Encrypt IP certificate (160-hour lifetime), conditional on successful public IP cost/renewal verification. Do not use quick tunnel as production. Restrict origin firewall and metadata access. No public DB.
B: one OCI VM with Caddy serving dist and proxying /api to FastAPI; same data volume; browser -> HTTPS origin -> static + /api -> IRSA. Same-origin simpler, no CORS and fewer services; frontend outage if VM down, no global static CDN unless separately configured.
C: Pages -> Cloud Run request-billed service (min 0, max 1, concurrency tuned) -> object cache and ephemeral scratch -> IRSA. Managed TLS provider URL. Requires refactoring file cache and handling cold starts, persistent journal separately; cannot promise zero bills. Container filesystem memory-backed by default. No always-on worker within free grant; use bounded synchronous requests or durable jobs only after measured costs. Azure Container Apps is similar alternative with temporary storage and Azure Files cost.
See decision matrix for tradeoffs, resource report for estimates, security audit for blockers and roadmap for approval gates.
